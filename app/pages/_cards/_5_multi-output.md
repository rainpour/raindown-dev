---
title: Multi-output
---

Render Markdown and/or HTML from the same component. Configure per component:

| Config | Inline   | Render           |
| ------ | -------- | ---------------- |
| **#1** | Markdown | HTML             |
| **#2** | Markdown | Markdown as HTML |
| **#3** | HTML     | Markdown as HTML |
| **#4** | HTML     | HTML             |
