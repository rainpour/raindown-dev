Raindown is a Markdown superset for AI, APIs, docs and humans. Directives in your Markdown write content into the file, like tables of contents, charts, tables from CSV files, API responses and your own components, so people and agents reading it see the same thing.

Use it in one of three ways:

  <a class="way" href="/docs/cli">
    <img src="/assets/raindown.svg" alt="Raindown">
    <div>
      <strong>CLI</strong>
      <p>Browse a project in the terminal UI, write back to its files as they're saved, and render them to HTML.</p>
    </div>
  </a>
  <a class="way" href="/docs/obsidian">
    <img src="/assets/obsidian.svg" alt="Obsidian">
    <div>
      <strong>Obsidian</strong>
      <p>Write back to your notes as you save them, with directives highlighted as you type.</p>
    </div>
  </a>
  <a class="way" href="/docs/vscode">
    <img src="/assets/vscode.svg" alt="VS Code">
    <div>
      <strong>VS Code</strong>
      <p>Highlight Raindown syntax and preview your files, rendering as you type.</p>
    </div>
  </a>
</div>
